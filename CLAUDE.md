# k8s-1.38

The `kubex-k8s-1-38` package: Pydantic v2 models for Kubernetes 1.38, used by kubex
(kubex-py/kubex) through the `kubex[k8s-1.38]` extra. Split out of kubex's workspace
(`packages/kubex-k8s-1-38`) with its history.

## Generated code

`kubex/k8s/v1_38/` is generated by kubex-codegen (kubex-py/kubex-codegen). Never edit it by
hand; a change to the models is a change to the generator, released as a new
kubex-codegen tag. The tag this repo uses is in `.kubex-codegen-version`.

- Regenerate: `mise run regenerate` (see the README), then `uv lock`
- The Regenerate workflow does it weekly and opens a pull request when anything changes.

## Hand-written files

- `pyproject.toml`: keep its `[tool.ruff]` settings and the ruff and mypy pins in the dev group
  equal to kubex-codegen's, or the repo's own lint will disagree with the generated code
- `tests/`: behaviour of the generated models against real API payloads
- `.github/workflows/`: CI and publishing through kubex-py/.github's reusable workflows, and
  `regenerate.yaml`. Workflow files are named `.yaml`.
- README, CHANGELOG, LICENSE, `mise.toml`, `.kubex-codegen-version`

## Commands

`uv sync`, `uv run pytest`, `uv run ruff check .`, `uv run mypy kubex tests`. `uv.lock` is
committed; CI syncs with `--locked`.

## Releases

Own version numbers. Bump `version` in `pyproject.toml`, update `CHANGELOG.md`, merge, then push
a `vX.Y.Z` tag on `main`.
